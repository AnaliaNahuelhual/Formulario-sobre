Ciberseguridad y Resguardo Digital

Descripción del Proyecto

Sitio web completo y responsive desarrollado como proyecto final, enfocado en servicios de ciberseguridad, prevención de vulnerabilidades y resguardo digital. Consta de cinco páginas independientes conectadas mediante una navegación fluida, incorporando un diseño moderno, interactividad avanzada con JavaScript, persistencia local y consumo de una API pública.

 Autora

Analia Nahuelhual

 Objetivos del Proyecto

Proveer información institucional clara y profesional sobre ciberseguridad y buenas prácticas informáticas.

Ofrecer una experiencia de usuario (UX) única e interactiva a través de un formulario de consulta integrado dentro de un sobre animado con CSS y JavaScript.

Cumplir con los estándares técnicos solicitados: HTML semántico, diseño adaptable, manejo del DOM, almacenamiento local (localStorage) y consumo de APIs mediante fetch.

🛠️ Tecnologías y Herramientas Utilizadas

HTML5: Estructuración semántica con etiquetas modernas (<header>, <nav>, <main>, <section>, <footer>).

CSS3: Estilos avanzados, variables personalizadas (:root), Flexbox, transiciones suaves y Media Queries para diseño adaptable a celulares, tablets y escritorio.

JavaScript (ES6+): Manipulación dinámica del DOM, gestión de eventos (addEventListener), validaciones con expresiones regulares (RegEx), control de excepciones (try...catch) y peticiones asincrónicas.

Git y GitHub: Control de versiones, historial de commits y despliegue del sitio online.

 Funcionalidades Principales

Navegación Multipartida: 5 páginas HTML interconectadas (index.html, nosotros.html, servicios.html, consejos.html, Trabaja con Nosotros.html).

Formulario Interactivo en Sobre: Animación en CSS puro controlada desde JavaScript para abrir y cerrar el contenedor del formulario.

Validación y Persistencia Local: Validación estricta de campos obligatorios y formato de correo electrónico, con guardado automático de consultas en el localStorage del navegador mediante objetos y formato JSON.

Herramienta de Seguridad (API Pública): Consumo asincrónico de la API de red IP (ipify) con gestión de estados de carga, manejo de errores y renderizado dinámico de datos externos en el DOM.

Protección Anti-Spam: Sistema de revelado seguro de correos electrónicos para evitar la indexación por parte de bots.
